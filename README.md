# Bank Reconciliation Statement Analysis

## About the Project

This project demonstrates the preparation and analysis of a Bank Reconciliation Statement (BRS) by comparing accounting ledger records with bank statement transactions.

The project focuses on identifying discrepancies, analyzing reconciliation differences, and documenting the required accounting adjustments.

## Tools Used

- Microsoft Excel
- Financial Accounting
- Bank Reconciliation techniques

## Project Components

- Bank Reconciliation Statement analysis
- Ledger and bank statement comparison
- Journal entries for identified adjustments
- Memo report documenting findings
- Excel-based analysis

## Key Findings

The analysis identified various differences between the accounting records and bank statement, including:

- Opening balance discrepancy
- Omitted transactions
- Duplicate expense entries
- Under-recorded vendor payments
- Bank-originated transactions not recorded in the ledger
- Timing differences

## Skills Demonstrated

- Bank Reconciliation

## Project Outcome

The project provided practical experience in analyzing bank and ledger records, identifying discrepancies, preparing accounting adjustments, and documenting financial findings.
